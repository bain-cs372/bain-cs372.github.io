Activity 1. Modify the Wolf Sheep Simple Model

Take a model in the NetLogo Models Library where agents communicate or interact spatially with nearby agents (or build a new one). Extend the model so agents communicate across a network instead of spatially. In the INFO tab, please answer the following questions: When would you use each of these two modes of the model? What advantages does each topology have? Disadvantages? Compare the results of the two models. 400 level students (and, optionally, 300 level students), make sure you use BehaviorSpace to generate your comparison data.

Activity 2. Make a presentation

Prepare presentation slides comparing the two topological configurations of the model. Compare the differences between the mechanism underlying the two modes and the results from running the spatial vs. network-based versions of the model.

Include a reflection slide on the process of transitioning a model from “spatial” to “networked” communication. Compare your new network model to some of the different types of networks from Chapter 5 (e.g., random, scale-free, small-world) etc. When you set about to create your network topology, did you have one of these types in mind or did the model itself seem to imply one of the topologies?
