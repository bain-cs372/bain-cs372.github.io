Activity 2. Presenting a model

Browse the NetLogo models library (File Menu > Models Library) and select one model from the Sample Models folder that you find interesting. Please **do not** choose a model from the following folders: Games, System Dynamics, any “(unverified)” models, and Art models (except GenJam – Duple and Sound Machines). Please claim your model on the pinned edSTEM post. It is first-come first-served, so if someone else has already claimed that model, please choose another. We want to make sure that each student picks a unique model.

For the model you have chosen, study the model and prepare a short (5-10 minute) presentation on it for next class (including PowerPoint / Google slides). We will choose a few students to present in class on Tuesday or Thursday. In your presentation, you should:

  1. explain what the model shows
  2. give a demonstration of the model
  3. describe why it is interesting, what is emergent, and how it works.

Additionally, what set of parameters gives you the most interesting behavior? Is there a way to change a parameter in a small way and get a very different behavior? Be sure to explicitly describe the rules the agents are following. Try running the model in different ways. What set of parameters gives you the most interesting behavior? This doesn’t need to be a long/fancy presentation!

Use the textual pseudo-code format below to describe the rules. The following example describes the rules for the Ants Simple model in the Chapter 1 folder of the IABM section of the NetLogo Models Library. Note the use of the first-person singular to describe each agent’s behavior.

Initialize:
  1. Create an ant nest in the middle of the world.
  2. Create three food piles in the corners of the world.
  3. Create POPULATION number ants all located in the nest.

At each clock tick:
  1. Each ant does:
    a. If I am not carrying food, then I will try to sense for a pheromone trail nearby. If I sense pheromone then I will turn toward its strongest source.
    b. If I am carrying food, I will turn toward the nest and drop pheromone on the ground below me.
    c. I will turn randomly a small amount and move forward.

  2. Each patch does:
    a. Evaporate a percentage (set by the EVAPORATION-RATE slider) of my pheromone.
    b. Diffuse a percentage (set by the DIFFUSION-RATE slider) of my pheromone to my eight neighboring patches.
